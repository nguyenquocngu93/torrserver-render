# Arctic Fuse 2 Touch Mod

Mod giao diện Arctic Fuse 2 cho touchscreen (điện thoại/tablet).

## Tính năng
- **Touch targets lớn hơn**: 100px → 140px (dễ bấm hơn)
- **Mouse/touch enabled**: Bật mặc định
- **Touch-friendly navigation**: Giảm độ sâu menu

## Cài đặt trên Kodi

### Cách 1: Install from zip
1. Copy file `skin.arctic.fuse.2.touch.zip` vào điện thoại
2. Mở Kodi → Settings → Add-ons → Install from zip file
3. Chọn file zip đã copy
4. Khi xong → Settings → Interface → Skin → Chọn "Arctic Fuse 2 Touch"

### Cách 2: Manual copy (nếu có Termux)
```bash
# Copy vào thư mục addons của Kodi
cp -r skin.arctic.fuse.2.touch ~/.kodi/addons/
```

## Số liệu đã thay đổi

| Element | Gốc | Touch Mod |
|---------|-----|-----------|
| ButtonMenu items | 100x100 | 140x140 |
| ContextMenu items | 100x100 | 140x140 |
| FixedList containers | 100px | 140px |

- Nếu không thấy skin → restart Kodi
- Nếu touch không hoạt động → Settings → System → Input → Enable mouse/touch
